## 📝 My Notes
- CIA Triad is the foundation of all cybersecurity
- Confidentiality = data sirf authorized log hi dekh sakein
- Integrity = data modify na ho bina permission ke
- Availability = system jab chahiye tab available ho
- Security is about thinking like an attacker

## 🎯 Common Attacks
- **Phishing** — fake emails/links se credentials churaana
- **Malware** — harmful software install karaana
- **DDoS** — server ko requests se overwhelm karna

## 💡 Key Takeaway
> Security mindset means always asking —
> *"How could this be misused?"*
